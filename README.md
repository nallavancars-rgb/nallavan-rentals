# Nallavan Rentals

React and Vite app for the Nallavan Rentals website.

## Run locally

1. Install Node.js (LTS) and npm.
2. Run `npm install` in this folder.
3. Run `npm run dev` and open the local URL printed by Vite.

Use `npm run build` to create the production site in `dist/`.

The current migration mounts the existing site markup and booking integration through a React app entry point. The page styling, Google Sheets fleet feed, calendar sync, WhatsApp flow, and rental pricing rules are retained while the application is moved onto the React/Vite project setup.
